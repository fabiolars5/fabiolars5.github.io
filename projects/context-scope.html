AENOR coursework

Context & ISMS scope

  • ISO/IEC 27001
  • Context
  • Scope

Analysis of organisational context, stakeholder needs and boundaries to define what the management system covers.

Training context

Two separate training assignments: an organisational-context analysis using a known organisation as an academic reference, and a scope exercise based on a hospital scenario. They are not client engagements or a single implementation project.

Work carried out

  • Identify internal and external issues, interested parties and information security needs in the context assignment.
  • Relate relevant information and processes to confidentiality, integrity, availability and risk.
  • Select processes and activities for the proposed hospital scope, considering boundaries and dependencies.

Assessment rationale

A useful scope explains which activities and information are covered and how dependencies are handled. Defining it as a list of IT systems alone can overlook the people and processes that use the information.

Documented output

A documented context analysis and a separate proposed scope, with the reasoning for the processes included.

Scope & limitations

Educational analysis based on course scenarios and reference information. It does not demonstrate implementation or validation of an ISMS in the organisations used as examples.

Supporting work

Original materials remain private. We can discuss the methodology and which self-authored extracts can be shared after review.
