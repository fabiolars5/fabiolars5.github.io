Windows security baseline

Design and validation of a Windows security baseline to reduce risks related to accounts, services, remote access, events and insecure configurations.

  • Windows Server
  • GPO
  • Event logs
  • Accounts

Purpose

Document a repeatable baseline and a practical validation checklist for reviewing the security configuration of Windows systems.

Work covered

  • Review local policies, privileged accounts and authentication settings.
  • Consider remote access, firewall rules and unnecessary services.
  • Include event auditing and system configuration in the baseline.
  • Organise review criteria into a hardening guide and validation checklist.

Skills applied

Configuration assessment, baseline documentation and security validation.
